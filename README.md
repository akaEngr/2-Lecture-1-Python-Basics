# 📖 1. Overview

Lecture 1 introduces the fundamentals of Python programming. It covers the core concepts you need before moving on to intermediate topics such as Strings, Lists, Tuples, Dictionaries, Sets, Functions, Object-Oriented Programming (OOP), Django, and Django REST Framework (DRF).

By the end of this lecture, you should understand:

* Variables, data types, and keywords
* Operators and user input
* Modules and packages
* The difference between expressions and statements
* Basic practice programs

# 📂 3. File-by-File Explanation

## 01-firstProgram.py

This file introduces your very first Python program.

Topics covered:

* `print()`
* Built-in functions
* `input()`
* `type()` and type conversion
* `len()`, `max()`, `min()`, `sum()`, `range()`
* `sorted()`, `enumerate()`
* `zip()`
* `help()`

This file helps you understand the basic structure of a Python program and introduces commonly used built-in functions.

---

## 02-characterSet.py

This file explains the Python character set.

Topics covered:

* Letters, digits, symbols, and whitespace characters
* ASCII and Unicode
* Escape sequences (`\n`, `\t`, `\r`, `\f`)
* `ord()` and `chr()`
* How Python stores and processes characters

This file provides the foundation for understanding text handling in Python.

---

## 03-variables.py

This file explains variables in Python.

Topics covered:

* What a variable is
* Identifier vs. Variable
* Memory storage
* References and object identity
* Multiple variables pointing to the same object
* Mutable and Immutable objects

Variables are one of the most important concepts in Python because they are used throughout programming.
